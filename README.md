# SPSMB Backend API

Backend untuk aplikasi Seleksi Penerimaan Santri dan Murid Baru (SPSMB).

## Requirement
- Node.js
- MySQL

## Setup
1. Buat database MySQL dengan nama `spsmb_asy_syadzili`.
2. Copy `.env.example` ke `.env` dan sesuaikan koneksi database.
   ```bash
   cp .env.example .env
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Jalankan mode development:
   ```bash
   npm run dev
   ```

## Informasi API
- Base URL: `http://localhost:3000/api/v1`
- Database Name: `spsmb_asy_syadzili`
